# nagi｜美容サロンWebサイト改善ポートフォリオ

方南町の架空プライベートサロン「nagi」を題材にした、Webサイト改善ポートフォリオです。

## 公開ページ

- 修正後版：`index.html`
- 修正前版：`before/index.html`
- 改善ケーススタディ：`case-study.html`

## 想定案件

クラウドソーシングで募集される、個人美容サロンの1ページサイト新規制作・リニューアル案件を想定しています。

## 修正前版の問題

1. 店の特徴・対象・場所が最初に分かりにくい
2. メニュー説明と料金が離れている
3. 初回利用の流れがない
4. CTAの文言が統一されていない
5. 営業時間と利用条件が下部に埋もれている
6. スマートフォンの余白・料金表・ボタンが見にくい

修正前版は壊れたページではなく、実在しそうな「少し整理不足のサイト」として制作しています。修正後版では同じサービス、料金、店舗情報を基本に、情報の順番、見出し、余白、CTAを改善しました。

## 使用技術

- HTML
- CSS
- 最小限のインラインJavaScript（デモ注記の表示のみ）
- 外部ライブラリ・外部画像なし

## 安全表示

店舗、住所、サービス、価格、連絡先はすべて架空です。問い合わせ操作はデモであり、送信・保存・予約確定は行われません。
